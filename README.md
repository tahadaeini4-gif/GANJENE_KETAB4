# گنجینه ی کتاب

همه فایل‌ها کنار هم در یک پوشه (بدون زیرپوشه) قرار می‌گیرند.
اجرا: `node server.js` (Node.js 18+). فایل‌های ظاهری (بوت‌استرپ، آیکن، فونت، xlsx) اگر نباشند و سرور اینترنت داشته باشد، خودکار کنار همین فایل‌ها دانلود می‌شوند (یا `node fetch-libs.js`).
داده‌ها در پوشه `data` (خودکار ساخته می‌شود) ذخیره می‌شود. سایت باید حتماً از طریق سرور Node باز شود (نه با دابل‌کلیک روی index.html و نه GitHub Pages)، وگرنه تغییرات ذخیره نمی‌شود.
